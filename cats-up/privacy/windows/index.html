Privacy Policy — Cats Up Desktop for Windows

Last updated: September 10, 2026

This policy covers the Windows version of Cats Up Desktop, distributed through the Microsoft Store. The macOS version has its own policy: Cats Up — Privacy Policy (macOS).

Cats Up Desktop is a clipboard manager and file drawer that runs entirely on your own computer. It has no user accounts, no servers of ours, no analytics, and no advertising. Everything it keeps stays on your device, with one exception you control: a bug report you choose to send (see What leaves your device).

What the app stores, and where

To work as a clipboard manager, the app keeps a history of what you copy and capture:

WhatWhat is stored
Copied text and linksThe text itself (up to 50,000 characters per item)
Copied images (image data)The image, saved as a PNG file in the app's own data folder
Screenshots you takeThe image file, copied into the app's own data folder (and, unless Keep the original file is on in Settings, removed from your screenshots folder)
Screen recordings you makeThe video file, moved into the app's own data folder
Files you copy in File ExplorerOnly a reference — the file's path, name, size and type. The file itself is never copied or moved.
Files you downloadOnly a reference, as above
Folders you add to the Local tabThe folder's path, so it can be shown again next time
Your settingsLanguage, sort order, window size, and which capture types are enabled

All of this is stored locally and unencrypted in the app's per-user application-data folder — it has the same protection as any other file in your Windows user account, and nothing more. For the Microsoft Store build this is inside the app's package data under %LOCALAPPDATA%\Packages\; a directly-downloaded build uses %APPDATA%\Cats Up Desktop. Nothing is written outside your own user profile.

Please understand what a clipboard history means. If you copy a password, a recovery code, or anything else sensitive, it is saved as plain text like any other copied text. Delete such items from the app when you are done, or turn off text capture in Settings before copying them.

What the app watches on your computer

  • The clipboard, checked about twice per second while the app is running, so text, links, images, and copied files appear in the drawer.
  • Pictures\Screenshots, so a Win+PrtScn or Snipping Tool capture appears automatically.
  • Videos\Captures, so an Xbox Game Bar (Win+Alt+R) recording appears automatically.
  • Your Downloads folder, to notice newly finished downloads.
  • Folders you add yourself to the Local tab — listed only while you browse them.

Because you can move those Windows folders, the app also performs a read-only query of your own user registry (the User Shell Folders values under HKEY_CURRENT_USER) to find where they actually are. It reads nothing else from the registry and writes nothing to it.

The app does not scan, index, or upload the rest of your disk, and it does not read the contents of files it has not been asked to handle.

Windows permissions the app uses

Cats Up Desktop is a full-trust desktop application (runFullTrust). That is what lets it read the clipboard, notice new files in the folders listed above, provide native drag-and-drop into other applications, show a tray icon, and respond to a global show/hide shortcut. It uses that access for those purposes only. It requests no camera, microphone, location, contacts, or account access, and it does not capture your screen itself — screenshots and recordings are made by Windows, and the app simply picks up the resulting file.

Files the app moves or deletes

So a capture lives in one place instead of two, the app changes files in these cases — and only these:

  • A screenshot it captures is removed from your Pictures\Screenshots folder once it has been added to the app — unless Keep the original file is on under Images in Settings, in which case the file stays where Windows saved it and the app keeps its own copy.
  • A screen recording it captures is moved out of Videos\Captures into the app's own data folder.
  • Deleting such an item in the app sends the file to your Recycle Bin where possible, rather than destroying it.
  • Files you merely copied or downloaded are never touched. Removing that entry removes the entry only; your original file stays exactly where it is.
  • Actions you explicitly choose in the Local tab — rename, duplicate, compress, move to Recycle Bin, or dragging a file into a folder — do exactly what they say, to the files you selected.

You can switch off any capture type — texts, images, videos, links, files — in Settings. With images off, for example, your screenshots stay in your screenshots folder untouched, exactly as if the app were not running.

What leaves your device

One thing, and only if you choose to send it: a bug report.

If you open Report a bug and press Send, the app transmits what you typed — the subject, the description, and your email address if you chose to provide one — together with the app version and your platform name (win32). It is sent over HTTPS to Web3Forms (api.web3forms.com), a third-party form-to-email relay, which forwards it to the developer's inbox at jejiegypt@gmail.com. It is used only to answer and fix the problem you reported. See Web3Forms' privacy policy for how they handle that message in transit.

Nothing else is sent. The app makes no other network requests: no analytics, no telemetry, no crash reporting, no advertising, no third-party SDKs or trackers, and no update checks of its own (updates are delivered by the Microsoft Store). No clipboard content, screenshot, recording, file, or folder information is ever transmitted — not to us, not to anyone. The only other time the network is involved is when you click a link in a captured item, which opens it in your default browser.

Your data is never sold, rented, or shared. There is no third party with access to it, because it does not leave your computer.

How long data is kept, and how to delete it

  • Delete a single item with the × on its card.
  • Empty one category, or everything, with the trash-bin button (it asks for confirmation first).
  • Uninstalling the app removes its stored data, because the Microsoft Store build keeps everything inside its own per-user package data.

A bug report you chose to send stays in the developer's email inbox. Write to jejiegypt@gmail.com and it will be deleted on request.

Children's privacy

Cats Up Desktop is a general-purpose utility. It is not directed at children, and it collects nothing about who is using it.

Your rights

Because nothing about you is stored on any server, there is no account to access, export, or close and no profile to correct. Your data sits in the folder named above, on your own machine, and you can read or delete it at any time. For anything you sent in a bug report, contact jejiegypt@gmail.com to see or delete it.

Changes to this policy

If the app's behaviour changes in a way that affects this document, this page is updated before that version ships and the "Last updated" date above changes. Material changes are also described in the app's release notes.
